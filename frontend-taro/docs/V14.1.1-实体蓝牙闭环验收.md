- 实体设备：`PDD_CB724E`，地址 `AD:FF:3D:CB:72:4E`。
- 设备信息：固件 `3.9`、104×104、MTU 512、Write Without Response 有效载荷 509 字节。
- 应用修复：H5 Web Bluetooth 与 APK/Tauri 原生 BLE 均已接入 PDD V1.4；旧版 BeadCraft 继续兼容。

## 应用链路

- 设备过滤同时支持 `PDD_` 与 `BeadCraft-`。
- PDD 连接后立即读取并校验设备信息；状态心跳读取真实亮度。
- 现有 64×64 RGB565 画布在适配器内按设备尺寸转换为 104×104 RGB888。
- 图案按最大 4096 字节协议帧拆分，并继续按 ATT 载荷拆分写入；逐帧校验状态 3/1。
- 颜色高亮根据最后下发图案计算真实坐标，并按 50ms 帧间隔发送。
- PDD V1.4 未定义 WiFi 配网和支付授权命令，应用会明确报错并阻止发送旧协议包。

## H5 与 APK 验收

- H5 连接：Chrome `localhost` 页面经系统选择器连接 `PDD_CB724E`，页面显示 `已连接设备 CB724E`。
- H5 页面栈：在保持 GATT 连接的情况下进入素材库，筛选 104×104、套用“蓝宝石”并返回编辑器；设备按钮仍为 `CB72`，未重新扫描或重连。
- H5 图片闭环：用户只在系统文件选择器中选择测试图；网格校准、裁剪、本地量化、配色和 RGB888 封包均在前端执行。最终生成 104×104、41 色图案，真实下发后设备保持在线。
- H5 高亮：点击 H6 后网页状态为 `active: H6`，设备传输无报错；再次点击清除高亮并恢复完整图案。设备监测显示 `CB724E`、亮度 25、告警 0。
- APK：最终 APK 在 Android 15 x86_64 模拟器清空应用数据后安装成功，系统回读 `versionName=14.1.1`、`versionCode=140101`；冷启动、首页、本地图册、豆仓、我的、104×104 参数页和编辑器均实际打开正常。
- APK 原生 BLE：授予测试模拟器附近设备权限后，日志确认 `blec` 权限检查、适配器状态读取、`start_scan`、`stop_scan` 和 Android BLE Scanner 注册实际执行；模拟器没有实体板，未伪报 APK 实机连接。
- 稳定性：应用 PID 持续存活且保持前台；应用进程日志未出现 `FATAL EXCEPTION`、应用 ANR、Rust panic 或进程异常死亡。测试工具自身的 `UiAutomation` 退出不计为应用故障。
