# DIY 拼豆 v14.2.0 参考功能整合验收

## 结论

- 保留现有 v13/v14 页面结构、配色、角色图与交互风格。
- 从“整理版”只吸收通用功能思路：素材搜索历史、素材离线收藏、作品用量与豆仓核对、蓝牙连接诊断、PDD 设备信息展示。
- 未复制参考应用的品牌、角色图片、专属 UI、模型文件或来源不明图标。现有通用图标与当前 UI 一致，未做无必要替换。

## 新增闭环

| 功能 | 结果 | 实现边界 |
|---|---:|---|
| 素材搜索历史 | ✅ | 最多保存 20 条；去空格、去重、最近优先；支持点击复用和清空。 |
| 素材收藏到本地图册 | ✅ | 六种目标钉板均可收藏；同一来源、素材和尺寸重复收藏时更新原记录；断网仍可继续编辑。 |
| 素材到豆仓 | ✅ | 收藏作品可进入编辑器，通过“豆仓核对”直接查看各色需求、库存、余量和缺口。 |
| 按作品扣减库存 | ✅ | 库存充足才允许扣减；一次性原子扣减，不产生负库存；确认后支持一次撤销；手动盘点后撤销失效。 |
| 蓝牙连接诊断 | ✅ | 显示安全环境、蓝牙能力、已授权设备和当前 GATT 连接四项状态。 |
| PDD 信息监测 | ✅ | 状态心跳展示真实亮度、板型和旋转角度；协议 `passwordFlag` 按“密码预留标志”原值展示，不冒充付费锁状态。 |

## 协议边界

- 《拼豆屏 BLE 通信协议 V1.4》明确 `passwordFlag` 为预留字段，不能解释为设备已锁定或未锁定。
- V1.4 设备的真实付费锁状态仍不能从硬件信息响应推导；生产锁机必须使用下位机确认的锁机命令或已有付费锁接口。
- 本版没有重新连接或改写实体拼豆板状态，沿用 v14.1.1 已验收的 PDD V1.4 连接与传输实现。
