# PixelDoodle 最新开发基线

更新日期：2026-08-26

## 当前版本

- 应用版本：`14.2.0`，Android `versionCode=140200`。
- 开发分支：`codex/v14.2.0`。
- 当前 UI：继续使用工程自己的 v13/v14 UI；不得用参考 APK 的品牌、角色或专属界面覆盖。
- 当前平台：H5 与 Tauri Android；微信小程序和 iOS 不在本期验收范围。

## 已完成

- 六种钉板、自由像素编辑、撤销重做、缩放、本地保存、PNG/PDF/JSON 导出。
- 图片导入、网格校准、裁剪、前端本地量化、五套配色和一键重新匹配。
- 64,268 份素材母库、1,200 份 APK/H5 离线精选、中文分类、搜索、六尺寸适配、搜索历史、离线收藏和二次编辑。
- 本地图册、作品恢复、素材收藏、作品到豆仓用量核对、原子库存扣减和一次撤销。
- PDD V1.4 的 H5 Web Bluetooth 与 APK 原生 BLE 连接、设备信息、图片传输及高亮；连接诊断和亮度、板型、旋转信息展示。
- 支付锁机、私有云和分润的软件沙盒与接口契约保留；生产支付、对象存储和代付仍需外部接口。

## 不能越界宣称

- V1.4 的 `passwordFlag` 是预留字段，不是付费锁状态。
- 未接真实商户、正式云存储或代付渠道时，只能称软件沙盒完成。
- 温度、电压、电流和硬件故障码没有协议数据源时不能伪造监测。
- 本版未重新执行实体拼豆板测试；实体 PDD V1.4 基线沿用 v14.1.1 验收结果。

- 前端：59 个测试文件、205 项通过。
