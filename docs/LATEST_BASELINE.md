## 2. 合并决策

| 领域 | 最新基线结论 |
|---|---|
| v13 外观与本地创作 | 保留当前任务已验收的 v13 H5/Tauri Android UI、自由创作、导入、校准、编辑、保存和导出。 |
| 素材库 | 服务器母库保留 64,268 份；H5/APK 内置 1,200 份离线精选数据。两者不是互相替代关系。 |
| 支付、私有云、分润 | 保留另一任务已经实现的本地沙盒业务层、API、前端入口和测试；统一标记为“软件沙盒完成、生产外部服务未接”。 |
| 设备付费锁 | 服务端订单、授权令牌和旧 BeadCraft 固件握手代码保留；不能据此宣称 BLE V1.4 真实设备已经支付解锁。 |
| BLE 协议 | 《拼豆屏 BLE 通信协议 V1.4》及 `bead-screen-ble-v1_4.ts` 是后续真实拼豆屏接入的协议基准。当前生产适配器仍是旧 BeadCraft 协议，尚未切换。 |
| 设备监测 | 旧适配器已有亮度心跳、离线和传输告警；BLE V1.4 的硬件信息响应已有纯解析代码，但尚未接入真实 Notify 流。 |
| 云端生成 | 本地像素量化为默认闭环；万相 CloudBase 代码保留，但不计入当前本地交付验收。 |
| 微信小程序与 iOS | 当前基线不验收、不继续开发，除非后续用户明确重新纳入。 |

## 3. 当前可作为完成项的功能

### 3.1 本地 H5/Tauri Android

- 六种钉板：29×29、32×32、52×52、78×78、104×104、104×74。
- 自由像素创作、涂色、橡皮擦、填充、撤销、重做、缩放、清空。
- 96、120、144、168、221 色专业配色及一键套用。
- PNG/JPG 导入、目标网格校准、拖动、缩放、复位、本地像素化。
- 本地草稿、历史保存和恢复。
- PNG、PDF、JSON 导出。
- 首页、本地图库、豆仓、我的四个主入口。
- Android v13.0.1 通用调试 APK，包含 arm64-v8a、armeabi-v7a、x86、x86_64。

### 3.2 素材库

- 64,268 份服务器母库数据。
- 1,200 份 H5/APK 内置离线精选素材。
- 来源、中文分类、中英文标签、关键词、目标钉板筛选。
- 素材套用、尺寸适配、进入编辑器、二次编辑和保存。

### 3.3 沙盒商业模块

- 服务端权威价格、幂等订单、签名回调、支付事件防重。
- 私有作品创建、版本更新、用户隔离、软删除、恢复和 SHA-256 完整性。
- 不可变收益台账、基点分配、结算批次、收益查询和 CSV 导出。
- 生产环境缺少真实适配器时失败关闭，不自动降级为沙盒。

这些功能是可运行的软件沙盒，不代表微信/支付宝真实收款、正式云存储或真实代付已经接通。

### 3.4 BLE V1.4 上位机协议层

- `PDD_` 设备名和广播 ID 解析。
- 服务 `0x00FA`、Write `0xFA02`、Notify `0xFA03`。
- 小端帧编解码、长度校验和 BLE 写分片。
- 时间同步、清空、亮度、版本、旋转、画板模式、实时画板、高亮和屏幕开关。
- DIY 图片、保存图片和高亮坐标的 4096 字节协议分包。
- CRC-32/IEEE 默认实现、硬件信息/版本/ACK 解析。

## 4. 不能标记为真实闭环的部分

- BLE V1.4 真实设备扫描、连接、Write/Notify 和屏幕显示效果。
- BLE V1.4 下的支付解锁：PDF 未定义支付授权命令，旧 `0x0B/0x0C/0x0D` 握手不能自动视为 V1.4 标准。
- 微信支付、支付宝、真实回调域名和商户证书。
- OSS/COS/S3 等正式私有云与生产账号体系。
- 银行、钱包或支付平台真实代付、退款冲正和正式财务规则。
- 温度、电压、电流和硬件故障码监测。
- 微信小程序和 iOS 当前版本验收。

## 6. 后续开发规则

1. 先查本文和 `功能开发状态.md`，不得用任一旧任务中的过时完成率覆盖当前状态。
2. 真实拼豆屏接入只以 `docs/protocols/拼豆屏BLE通信协议V1.4.md` 为协议来源。
3. V1.4 PDF 中未定义的支付解锁命令必须由下位机团队确认，不能擅自把旧 BeadCraft 控制字并入标准。
4. 真实 BLE 适配器先通过功能开关与旧适配器并存，完成模拟传输测试后再接样机。
5. “沙盒完成”和“生产接通”必须分别标注；没有真实商户、云存储或代付资料时不得宣称商业闭环。
6. 每次修改保持前端协议测试、全前端测试、后端测试和 H5 构建通过。
